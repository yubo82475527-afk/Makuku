# 真实市场价格异步导出设计

## 目标与范围

将“真实市场价格”列表的 CSV 导出从同步 HTTP 下载改为异步任务。用户点击列表中的导出按钮后，系统保存当时的筛选条件并创建任务；任务完成后，用户从顶部 **Exports** 下载 CSV。

本次只覆盖真实市场价格导出。CSV 的列、筛选语义和文件格式与当前同步导出保持一致，不改变价格事实、列表查询或其他导出能力。

## 用户与权限

面向已登录的管理端用户。创建、查询任务列表和下载文件均使用服务端会话校验：

- 仅管理员角色可创建任务；
- 任务列表仅返回 `requested_by` 为当前用户的记录；
- 下载接口必须再次校验任务归属，不能只依赖前端隐藏；
- 后台 runner 仅接受 Cron 密钥或管理员会话。

## 方案选择

为价格导出建立独立的持久化任务，而不复用 `store_visit_monitor_export_jobs`：两者的事实来源、筛选、文件格式和生命周期各自独立。顶部 Exports 组件通过两个受保护的列表接口聚合展示，避免为本次需求重构成泛化任务框架。

## 数据与处理流

新增 `price_snapshot_export_jobs`，字段与现有巡店导出任务保持必要一致：`id`、`status`（`queued`/`running`/`completed`/`failed`）、`filters`（JSONB）、`locale`、`requested_by`、`total_rows`、`exported_rows`、`file_path`、`file_size_bytes`、`error_message` 与生命周期时间戳。对 `(status, created_at)` 和 `(requested_by, created_at)` 建索引。

1. 列表页把已生效的筛选条件与语言传给价格导出创建接口。
2. 接口完成管理员会话校验，清洗白名单筛选条件，写入 `queued` 任务，并在响应结束后触发 runner。
3. runner 原子领取 `queued`/`running` 任务，使用与现有同步导出相同的价格筛选和 CSV 映射读取数据，分批更新进度。
4. runner 将 UTF-8 BOM CSV 上传到现有受控 Storage bucket 的价格导出前缀，随后把任务标为 `completed`。异常则记录受限错误信息并标为 `failed`。
5. Exports 打开时加载用户自己的巡店和价格任务；存在进行中的任务时每 10 秒轮询。已完成任务显示下载按钮，按钮访问经服务端归属检查后签发的短期下载链接。

## 前端交互

真实市场价格列表保留“导出 CSV”入口，但点击后不再直接导航到文件下载，而是创建异步任务并显示“导出任务已创建，请在顶部 Exports 中查看进度并下载”。顶部 Exports 每项显示导出类型（“真实市场价格”或“巡店分析”）、状态、进度、创建时间、失败原因和下载入口。

## 错误处理与可观测性

任务创建失败在列表页显示错误提示。runner 失败不会把错误伪装为成功，任务在 Exports 中保留 `failed` 状态及安全的错误文本。重复点击允许创建独立任务；本期不引入取消、重试按钮、过期清理或跨用户共享。

## 验收标准

- 点击真实市场价格“导出 CSV”后不会同步下载，而会创建只属于当前用户的异步任务。
- 任务使用创建时的全部当前筛选条件，生成的 CSV 与原同步导出列和口径一致。
- 顶部 Exports 同时可查看巡店和价格任务，并对运行中任务展示进度、对完成任务提供下载。
- 非创建者无法通过列表、任务 ID 或下载接口查看或下载文件。
- runner 失败后任务显示失败状态，不影响其他任务。

## 测试策略

新增覆盖价格任务的筛选清洗、创建、归属隔离、CSV 内容、状态转换、失败写回和下载路径；补充顶部 Exports 聚合展示的结构与交互测试。保留并运行现有巡店异步导出测试，证明两类任务兼容显示。
