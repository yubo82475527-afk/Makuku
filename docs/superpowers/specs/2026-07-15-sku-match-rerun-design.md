# SKU 匹配重构与手动重跑设计

## 业务目标

内测阶段以稳定、可解释的商品匹配为目标。用销售提供的 327 条竞品档案替换当前有效竞品池，旧竞品只停用不删除；新 H5 和管理员主动选择的历史 Visit 使用同一套纯硬规则重新生成商品候选、审核状态和价格快照。

验收目标保持为自动匹配覆盖率不低于 60%、人工审计正确率不低于 98%。不使用概率型分数解释匹配结果。

## 使用角色与业务动作

经理和管理员在现有“巡店分析监控”页面执行两类动作：

1. 按 Visit Date 闭区间重跑匹配，例如 2026-07-01 至 2026-07-15。
2. 对列表中的某一个 Visit 单独重跑匹配。

普通用户不显示这些操作。移动 H5 不增加入口，也不改变拍摄操作。

## 主数据切换

导入前完整校验 Excel。任何错误都会终止替换，不修改数据库。校验通过后：

- 当前有效竞品全部改为 `disabled`，不物理删除。
- 清除停用竞品的 `sku_matches`，不删除竞品关联的历史价格事实。
- 327 条新竞品写为 `active`，通过现有触发器获得稳定 `competitor_sku_code`。
- Excel 中的 `piece_count` 已经是总片数，直接保存整数，不再计算或保存包装表达式。
- 自有品牌不得进入竞品池。

## 匹配模型

匹配输入标准化为品牌、系列、包装层级、形态、尺码、总片数和版本。归一化覆盖 `DRYCARE/DRY CARE/DRY-CARE`、`MEDIUM/M`、`LARGE/L` 和 `CELANA/PANTS` 等业务别名。

候选按固定顺序处理：证据归一化、品牌和系列解析、商品池选择、Signature 生成、硬过滤、唯一候选判断、绑定。停用商品、重复 Signature、字段冲突和多候选都不得自动绑定。

匹配方法只有：

- `EXACT_CODE`
- `FULL_SIGNATURE`
- `UNIQUE_SIGNATURE`
- `UNMATCHED`

`match_score` 仅保留兼容值：匹配为 1，未匹配为 0，不作为概率或审核依据。

## 手动重跑流程

手动重跑不调用图片解析 AI。它读取目标 Visit 已保存的 `offline_visit_images.vision_result`，并复用现有 H5 候选生命周期：

1. 选择日期范围或一个 Visit。
2. 读取有效价格图片和结构化 Vision 行。
3. 清理这些图片产生的旧价格快照。
4. 将旧候选标记为 `rejected + reanalyzed`。
5. 使用新主数据和 v2 规则创建新候选。
6. 触发现有质量门禁、自动审核和价格快照流程。
7. 刷新 Visit 状态和详情缓存。

重跑结果会替换 H5 详情当前展示的匹配 SKU；旧候选保留为非活动记录用于排查。

## 后台接口

新增管理员/内部接口 `POST /api/internal/store-visit-matching/rerun`。请求只能选择一种目标：`visit_id`、`visit_code` 或 `date_from + date_to`。日期区间包含首尾日期。混合选择、倒序日期和空结果均返回明确错误。

响应包含目标 Visit 数、成功/跳过/失败数、候选数、各 Match Method 数、替换快照数和逐 Visit 失败原因。内部自动化继续使用现有任务密钥，浏览器调用使用管理员会话。

## UI 交互

不新增页面。现有巡店分析监控页面增加：

- 列表工具栏的“重跑匹配”按钮，默认带入当前日期筛选范围。
- 每行 Visit 的“重跑匹配”操作。
- 一个共用弹窗，展示目标范围或 Visit、不会调用图片 AI 的说明、确认按钮、运行状态、处理计数和失败原因。

运行期间禁止重复提交。完成后刷新监控数据，用户可通过现有详情链接检查新的匹配 SKU、待审核/已审核状态和价格快照。

## 性能与安全

每批重跑只加载一次自有和有效竞品主数据并建立索引。每条候选只标准化一次，匹配循环中不执行数据库查询或 AI 调用。数据库写入按 Visit 批量处理，日期范围任务返回逐 Visit 结果，单个失败不隐藏其他 Visit 的执行结果。

物理删除竞品不在范围内。只有用户主动选择的 Visit 会替换候选和快照，未选择的历史 Visit 保持不变。

## 测试与验收

自动测试覆盖别名、尺码、形态、整数总片数、重复候选、停用候选、日期选择、单 Visit 选择、旧候选归档和禁止 AI 调用。构建前运行测试、Lint 和 Next.js Build。

上线前通过只读检查确认：327 条新竞品有效、21 个竞品品牌、自有品牌为 0、竞品编码唯一、旧竞品均停用。管理员分别执行一次日期范围和单 Visit 重跑，确认 H5 详情展示新匹配结果且移动端没有新增操作入口。
